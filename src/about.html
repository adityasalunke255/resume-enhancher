About

Resume Enhancer
This is a frontend-only resume builder that runs fully in the browser. Save profiles locally, choose templates, and export as PDF.
No backend required. For API features (image search, AI enhancements), paste your keys in the About page during a session.

Quick Tips

  • Use the Create page to fill in your info and generate a preview.
  • Use About to save your API keys locally (not stored in repo).
  • My Resumes shows saved resumes tied to your local profile.
