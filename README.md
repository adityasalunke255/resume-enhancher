# AI-Powered Resume Builder (Frontend Only)

## Features
- Upload info via form or JSON file
- Dynamically generate styled resume templates (JS + HTML/CSS)
- Export resume as PDF (html2pdf.js, all logic in browser)
- No backend required

## Usage
1. Open `src/index.html` in your browser.
2. Fill out the form or upload a JSON file with resume info.
3. Click "Generate Resume" to preview.
4. Click "Export as PDF" to download your resume.

## Tech Stack
- HTML, CSS, JavaScript
- [html2pdf.js](https://github.com/eKoopmans/html2pdf) (CDN)

## Customization
- Edit `styles.css` for template styles.
- Modify `script.js` for logic or template changes.

## No backend — all logic stays in browser.
